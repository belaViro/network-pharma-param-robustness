# 网络药理学靶点筛选的参数稳健性研究

## 一、研究背景与目标

### 1.1 传统网络药理学的"参数黑箱"问题

网络药理学已广泛应用于中药复方活性成分筛选和作用机制解析。然而，该领域存在一个**系统性缺陷**：几乎所有研究都依赖人为设定的阈值参数，却从不讨论**"为什么选择这个参数值"**以及**"换个参数结果会怎样"**。

| 常见硬编码参数 | 典型取值 | 问题 |
|--------------|---------|------|
| STRING PPI置信度阈值 | 0.4 / 0.7 | 没有系统论证 |
| SwissTarget Probability阈值 | 0 / 0.1 | 随意设定 |
| 核心靶点筛选数量 | Top-30 | 经验选择 |
| 富集分析P-value阈值 | 0.01 / 0.05 | 惯例沿用 |

这种"参数黑箱"导致：
- **结果不可重复**：不同研究用不同阈值，结论难以比较
- **假阳性风险**：靶点排名可能只是参数设定的偶然结果
- **科学性存疑**：审稿人常质疑"凭什么用0.4不是0.5"

### 1.2 研究目标

本研究提出**系统性参数稳健性分析框架**，对网络药理学靶点筛选的关键参数进行：

1. **参数敏感性分析 (Sensitivity Analysis)**
   - 系统扫描参数空间，识别哪些参数对结果影响最大
   - 回答：哪个参数"最要命"？

2. **不确定性量化 (Uncertainty Quantification)**
   - 采用Bootstrap置信区间评估结果可靠性
   - 回答：这个结果有多可信？

3. **稳健靶点识别 (Robust Target Identification)**
   - 筛选在参数剧烈变化下依然稳定出现的靶点
   - 回答：哪些是"无可争议"的核心靶点？

### 1.3 研究定位

| 创新类型 | 说明 |
|---------|------|
| **方法学创新** | 首次将系统性稳健性分析引入网络药理学靶点筛选 |
| **可靠性验证** | 为传统流程提供统计学支撑，而非替代方案 |
| **发表定位** | 中科院2-3区（纯生信）/ 稳2区冲1区（加验证） |

### 4.3 参数阈值选择的依据与边界条件

> **核心原则**: 参数扫描的范围不是"越宽越好"，而是必须覆盖"生物学有效区间"内的合理波动。超出有效区间的参数组合产生的不是"敏感性信息"，而是"无效噪声"。

#### 4.3.1 SwissTarget概率阈值 P_prob 的选择依据

**为什么不是 [0.0, 0.05, 0.1, 0.15, 0.2, ...]?**

通过预实验验证，我们发现靶点预测概率阈值与下游富集分析效果存在**非线性关系**，存在一个"有效区间":

| P_prob | 靶点数量 | 富集结果 | 评价 |
|--------|---------|---------|------|
| 0.0 | 282 | 通路丰富，核心信号稳定 | 有效（宽松边界） |
| 0.05 | 95 | 通路丰富，核心信号稳定 | 有效（推荐平衡点） |
| 0.1 | 54 | 通路精简但主干信号仍在 | 有效（严格边界） |
| **0.2** | **13** | **完全异常（CA基因劫持）** | **失效（跌破下限）** |

**关键发现——富集分析的"下限阈值"效应**:

当 P_prob ≥ 0.2 时，预测靶点数量锐减至 13 个。此时：
- 样本量不足以覆盖氧化应激相关通路的基因集
- 13个靶点中有7个属于碳酸酐酶（CA）基因家族
- 富集结果完全被CA家族劫持：氮代谢、碳酸氢盐转运等无关通路占据主导
- 氧化应激相关通路（MAPK/TNF等）完全消失

这说明：**富集分析存在"最小基因集"要求**。当输入靶点数量低于某个阈值（本数据集中约20-30个）时，富集分析失去统计意义，结果高度依赖随机抽样的基因组成，而非真实的生物学关联。

**因此，P_prob 的扫描上限确定为 0.1，而非继续扩展到 0.2/0.3。**

#### 4.3.2 STRING置信度阈值 P_string 的选择依据

| P_string | 网络规模 | 评价 |
|---------|---------|------|
| 0.3 | 较宽松，保留较多弱关联边 | 有效（验证低阈值敏感性） |
| 0.4 | 文献常用默认值 | 有效（推荐值） |
| 0.5 | 较严格，剔除弱关联 | 有效（验证高阈值影响） |
| 0.7 | 严格，仅保留强实验证据 | 有效（极端值验证） |

0.3 作为下限：验证当包含较弱关联时，核心靶点是否仍然稳健。  
0.7 作为上限：验证即使只保留强关联边，核心网络结构是否仍然保持。

#### 4.3.3 Top-K Hub数量 K_top 的选择依据

Top-K 的选择直接影响 PPI 网络中纳入富集分析的基因数量。K 太小会遗漏重要调控节点，K 太大会引入拓扑边缘的低关联基因。

| K_top | 占PPI节点比例 | 评价 |
|------|-------------|------|
| 25 | 约25-30% | 严格筛选，仅保留核心枢纽 |
| 30 | 约30-35% | 文献常用值（推荐） |
| 40 | 约40-50% | 较宽松，覆盖更多潜在节点 |

#### 4.3.4 富集分析P-value阈值 P_pvalue 的处理

在 MVP v2 中，P_pvalue 固定为 0.01，原因如下：
- 若同时扫描 P_prob 和 P_pvalue，参数空间呈指数膨胀（3×4×3×3=108组合）
- 预实验显示 P_pvalue（0.01 vs 0.05）对通路数量有预期内的平滑影响，不产生结构性突变
- P_pvalue 的敏感性在完整 A+E 分析中单独评估

#### 4.3.5 "方法参数扫描"与"报告阈值"的严格区分

**这是避免循环论证的关键设计**:

| 概念 | 定义 | 作用 |
|------|------|------|
| **方法参数扫描范围** | 分析阶段尝试的多种参数组合（如P_prob=[0.0,0.05,0.1]） | 评估结果的参数依赖性，识别稳健靶点/通路 |
| **报告阈值** | 最终论文采用的单一参数配置（如P_prob=0.05, STRING=0.4, TopK=30） | 呈现可重复的分析流程 |

**为什么必须区分两者？**

如果只用单一参数组合做分析，审稿人会质疑："换一组参数结果还成立吗？"  
但如果扫描了多种参数后，仍然选择最有利于自己结论的那一组作为"报告阈值"，又会陷入"挑选数据"的批评。

**解决方案**：
1. **方法层面**：系统扫描多种参数组合，量化靶点/通路在不同参数下的稳健性
2. **报告层面**：选择稳健性最高的参数组合作为"报告阈值"，并在论文中明确说明选择依据
3. **论证逻辑**："我们不是因为这组参数结果最好才选它，而是因为它在参数扫描中表现出最高的稳健性"

**举例说明**:
- 若 TNF 在 P_prob=0.0/0.05/0.1 的所有组合中均进入 Top-K → TNF 是"跨梯度稳健靶点"
- 若某基因仅在 P_prob=0.0 时进入 Top-K，在 P_prob=0.1 时被挤出 → 该基因是"条件依赖靶点"
- 报告阈值选择 P_prob=0.05 的依据：它处于"有效区间"的核心位置，既保证了靶点质量（排除低置信预测），又维持了足够的样本量（95个靶点）用于有意义的富集分析

#### 4.3.6 参数阈值疑问的系统回应

本研究在方法学层面需要回应以下关于参数阈值的常见质疑：

**Q1: 为什么概率阈值只到0.1，不继续收紧？**  
A: 当P_prob≥0.2时，靶点数量跌破富集分析的有效下限（约20-30个），导致CA基因劫持等伪阳性现象。参数扫描的边界应由生物学有效性决定，而非人为设定的数值范围。

**Q2: 概率阈值0.0是否太宽松，会引入大量假阳性靶点？**  
A: 0.0作为边界验证点是必要的——它回答了"即使纳入所有预测靶点，核心靶点是否仍然稳健？"若某靶点在282个预测靶点中都能进入Top-30，说明它在PPI网络中的拓扑重要性极高。但报告阈值不会选择0.0，而是选择稳健性与精确度的平衡点（0.05）。

**Q3: 参数扫描范围是否足够宽？**  
A: 参数扫描的"宽度"不等于"覆盖的数值范围大小"，而等于"覆盖的有效区间是否完整"。本研究的P_prob=[0.0,0.05,0.1]覆盖了从"宽松但核心稳健"到"严格但仍有效"的完整有效区间，比盲目扩展到0.2/0.3（超出有效区间）更合理。

**Q4: STRING阈值0.3是否太低？**  
A: 0.3作为下限用于验证"当包含较弱关联时，核心结论是否仍然成立"。若核心靶点在STRING=0.3和STRING=0.7下均稳定，则证明结论对STRING阈值变化不敏感。报告阈值选择0.4（文献默认值）。

**Q5: Top-K=40是否太多？**  
A: 40作为上限用于验证"当纳入更多Hub节点时，是否引入噪音并改变核心通路"。若核心通路在K=25和K=40时保持一致，则证明结论对Hub筛选数量不敏感。

**Q6: 最终报告的参数组合是如何确定的？**  
A: 报告参数组合的选择依据是"稳健性最大化"原则，而非"结果最显著"原则。具体而言：
- P_prob=0.05：处于有效区间的中心，兼顾靶点质量与富集有效性
- STRING=0.4：文献默认值，且核心靶点在该阈值下表现稳健
- TopK=30：文献常用值，且核心通路在该数量下表现稳定
- 该组合在参数扫描中的靶点/通路重合率最高，被评为"最优稳健参数"

### 4.4 参数敏感性分析 (Part A)

#### 4.4.1 分析指标

| 指标 | 定义 | 生物学意义 |
|------|------|-----------|
| 信号网络主干道数 | 属于 signaling_backbone 分类的通路数 | 反映核心信号网络的稳定性 |
| 交叉调控通路数 | 属于 cross_talk 分类的通路数 | 反映与氧化应激的功能关联 |
| 直接氧化应激通路数 | 属于 direct_ox 分类的通路数（GO层级验证） | 反映直接氧化应激响应（预期极少） |
| 显著通路总数 | P < P_pvalue的KEGG/GO通路总数 | 反映生物学效应广度 |
| 平均Enrichment Factor | 所有显著通路的EF均值 | 反映富集强度 |
| 核心靶点重合率 | 与固定参数结果的重叠比例 | 反映结果稳定性 |

#### 4.4.2 敏感性指标计算

```python
# 单参数敏感性: 当该参数变化时，结果的波动程度
def sensitivity_score(parameter_results: List[float]) -> float:
    """计算某参数取不同值时的结果标准差"""
    return np.std(parameter_results)

# 全局敏感性: Sobol-style分解 (可选扩展)

#### 4.5.1 Bootstrap重采样流程

```

### 4.6 稳健靶点识别的双层评估体系（主发现）

> **核心定位**：本研究以**稳健靶点识别**为主叙事，稳健通路为靶点稳健性的自然推论。靶点是网络药理学的"硬通货"，是后续实验验证的直接对象；通路是靶点集合的下游功能注释，其稳健性根植于靶点层面的稳健性。

#### 4.6.1 靶点频率与拓扑重要性统计

对于每个参数组合，记录进入Top-K的靶点及其拓扑指标：

```python
# 对于每个靶点T，收集两个维度的信息
target_stats = {}

for param_combination in all_combinations:
    top_k_targets, network = run_pipeline(param_combination)
    
    # 计算拓扑指标
    degree_dict = dict(network.degree())
    betweenness_dict = nx.betweenness_centrality(network)
    
    for t in top_k_targets:
        if t not in target_stats:
            target_stats[t] = {
                "frequency": 0,
                "degrees": [],
                "betweenness": [],
            }
        target_stats[t]["frequency"] += 1
        target_stats[t]["degrees"].append(degree_dict.get(t, 0))
        target_stats[t]["betweenness"].append(betweenness_dict.get(t, 0))

# 计算汇总统计
for t, stats in target_stats.items():
    stats["appearance_freq"] = stats["frequency"] / len(all_combinations)
    stats["avg_degree"] = mean(stats["degrees"])
    stats["avg_betweenness"] = mean(stats["betweenness"])
```

#### 4.6.3 二维评价体系：频率 vs 拓扑重要性

**关键问题**：若某靶点出现频率高（如90%），但每次都在Top-K里排名垫底（Degree刚好过线），它真的比出现60次但每次都是Degree第一名的靶点更"稳健"吗？

**解决方案**：建立二维评价体系，同时考虑"出现频率"和"出现时有多重要"。

- **X轴（稳健性）**：该靶点在多少参数组合中进入Top-K（Appearance Frequency）
- **Y轴（拓扑重要性）**：该靶点出现时的平均网络中心性（Average Degree / Betweenness Centrality）

**象限分类法（数据驱动，无需人为设定阈值）**：

```
                    高拓扑重要性（平均Degree大 / Betweenness高）
                              ↑
    ┌─────────────────────────┼─────────────────────────┐
    │  Q2: 低频高重要          │  Q1: ★★★ 核心稳健靶点    │
    │  （网络核心，但参数敏感）  │  （始终稳定且网络中心）    │
 低频率 ←─────────────────────┼─────────────────────────→ 高频率
    │  Q4: ○ 可忽略           │  Q3: ★ 稳健但边缘         │
    │                        │  （总是在，但不重要）       │
    └─────────────────────────┼─────────────────────────┘
                              ↓
                    低拓扑重要性
```

**象限划分依据**：以所有靶点的**频率中位数**和**平均Degree中位数**为界，自动分为四个象限。此为数据驱动分割，非人为规定。

| 象限 | 特征 | 生物学意义 | 论文定位 |
|:---|:---|:---|:---|
| **Q1（右上）** | 高频 + 高拓扑重要 | 参数变化下始终稳定且位于网络核心 | **核心发现**，重点讨论 |
| **Q2（左上）** | 低频 + 高拓扑重要 | 仅在特定参数下出现，但出现时是关键Hub | 参数敏感靶点，讨论其参数依赖性 |
| **Q3（右下）** | 高频 + 低拓扑重要 | 参数变化下始终出现，但拓扑边缘化 | 稳健但非核心，可能为背景靶点 |
| **Q4（左下）** | 低频 + 低拓扑重要 | 偶尔出现且不重要 | 可忽略 |

**举例说明**：
- **TNF**：在90%的参数组合中出现，平均Degree排名第3 → **Q1 核心稳健**
- **MMP9**：在85%的参数组合中出现，平均Degree排名第28 → **Q3 稳健但边缘**
- **PIK3CA**：只在30%的参数组合中出现，但出现时平均Degree排名第2 → **Q2 低频高重要**

### 4.7 稳健通路识别（靶点稳健性的自然推论）

> **核心定位**：通路的稳健性不是独立计算的，而是**靶点稳健性的自然推论**。只有先证明"靶点集合是稳健的"，才能说"这些靶点富集到的通路是稳健的"。因此，本节采用**双重验证策略**：(1) 独立计算通路的二维稳健性（频率+显著性强度）；(2) 验证通路是否由Q1象限的核心稳健靶点所驱动。

#### 4.7.1 参数敏感性与参数稳健性的概念辨析

本研究框架涉及两个密切相关但本质不同的概念，需在论文中明确区分：

| 维度 | **参数敏感性分析** (Sensitivity Analysis) | **参数稳健性分析** (Robustness Analysis) |
|:---|:---|:---|
| **核心问题** | "哪个参数对结果影响最大？" | "结果在参数扰动下是否稳定？" |
| **数学本质** | 方差分解、偏导数、相关系数 | 稳定性度量、置信区间、容差范围 |
| **输出形式** | 敏感性指数、参数排序、热图 | 稳健性得分、稳定区间、CI宽度 |
| **与本研究的关系** | **手段**：系统扫描参数空间 | **目的**：识别参数无关的稳健发现 |

**本研究的准确定位**：以**参数敏感性分析**为手段，实现**参数稳健性**的目的，最终识别出**稳健靶点**（主发现）与**稳健通路**（自然推论）。

论文写法建议：
- **标题/摘要**：使用"参数稳健性分析框架"（Parameter Robustness Framework）
- **Methods 2.1**：描述"Sensitivity analysis was performed by grid search..."
- **Results 3.2**：报告"Robust targets were identified using a two-dimensional framework..."
- **Results 3.3**：报告"Robust pathways were subsequently validated as the enrichment results driven by robust targets..."

#### 4.7.2 从稳健靶点到稳健通路的推导逻辑

**核心论证**：

传统网络药理学的叙事是 **化合物 → 靶点 → 通路 → 机制**。如果靶点本身不稳定（换了参数就不是这些靶点），那通路的"稳健"就是伪稳健——它反映的不是真实的生物学机制，而是参数设定的偶然结果。

本研究的推导链条：

```
Step 1: 参数敏感性扫描（200个组合）
        ↓
Step 2: 识别Q1象限核心稳健靶点（高频 + 高拓扑重要性）
        ↓
Step 3: 对核心稳健靶点集合进行富集分析（传统方法，固定参数）
        ↓
Step 4: 独立验证：这些通路是否在参数扫描中也高频高显著出现？
        ↓
结论: 通路稳健性 = 靶点稳健性 的交叉验证
```

**两种验证视角**：

| 验证视角 | 逻辑 | 作用 |
|:---|:---|:---|
| **靶点驱动验证** | Q1靶点富集到的通路，理论上应该是稳健的 | 主验证：从靶点推导通路 |
| **独立扫描验证** | 直接扫描200个组合的富集结果，看哪些通路高频高显著 | 交叉验证：确认靶点推导的通路确实独立稳健 |

只有当**两种视角一致**时（即Q1靶点富集到的通路同时也是独立扫描中的Q1通路），该通路才被认定为**核心稳健通路**。

#### 4.7.3 通路的二维评价体系（交叉验证用）

虽然通路是靶点的推论，但仍需独立验证其稳健性。采用与靶点对称的二维评价体系：

- **X轴（稳健性）**：该通路在多少参数组合中显著出现（Appearance Frequency）
- **Y轴（显著性强度）**：该通路显著出现时的平均显著性水平（Average -log10(Adjusted P-value) 或 Average Enrichment Factor）

**象限分类法（数据驱动，无需人为设定阈值）**：

```
                    高显著性强度（平均EF大 / 平均P值小）
                              ↑
    ┌─────────────────────────┼─────────────────────────┐
    │  Q2: 低频高显著          │  Q1: ★★★ 核心稳健通路    │
    │  参数敏感但重要           │  高频且显著性强          │
 低频率 ←─────────────────────┼─────────────────────────→ 高频率
    │  Q4: ○ 可忽略           │  Q3: ★ 稳健但效应弱      │
    │                        │  （可能为背景通路）       │
    └─────────────────────────┼─────────────────────────┘
                              ↓
                    低显著性强度
```

**象限划分依据**：以所有通路的**频率中位数**和**显著性强度中位数**为界，自动分为四个象限。此为数据驱动分割，非人为规定。

| 象限 | 特征 | 与靶点的关系 | 论文定位 |
|:---|:---|:---|:---|
| **Q1（右上）** | 高频 + 高显著 | 由Q1核心稳健靶点驱动 | **核心发现**，重点讨论 |
| **Q2（左上）** | 低频 + 高显著 | 由Q2参数敏感靶点驱动 | 参数敏感通路，讨论其参数依赖性 |
| **Q3（右下）** | 高频 + 低显著 | 靶点集合稳定但效应弱 | 可能为背景通路或基础代谢通路 |
| **Q4（左下）** | 低频 + 低显著 | 靶点不稳定且效应弱 | 可忽略 |

#### 4.7.4 关于"人为阈值"问题的回应策略

**核心矛盾**：若定义"频率≥80%为核心稳健通路"，则频率阈值本身又成为人为设定的参数，似乎陷入同样的"参数黑箱"。

**解决逻辑——区分"方法参数"与"报告阈值"**：

| | **方法参数**（如STRING=0.4） | **报告阈值**（如频率≥80%） |
|:---|:---|:---|
| **是否改变分析结果** | ✅ 是。改变后网络拓扑、靶点、通路全变 | ❌ 否。底层200个组合的计算已完成，频率只是事后统计 |
| **是否有替代选择** | ❌ 无。文献用0.4/0.5/0.7各说各话 | ✅ 有。可展示完整频率分布，读者自行判断 |
| **审稿人能否验证** | ❌ 难。传统方法从不展示"如果0.5会怎样" | ✅ 易。补充材料放完整频率表 |
| **统计基础** | ❌ "0.4"是经验值，无统计依据 | ✅ 基于Bootstrap频率分布，有明确统计含义 |

**详细论证（应对审稿人追问）**：

1. **透明性差异**：我们报告了所有靶点和通路的完整频率分布表（作为补充材料），频率阈值只是方便主文中分类讨论的辅助标签，读者可以看到原始数据。而传统方法从不报告"如果STRING=0.5会怎样"。

2. **可变性差异**：改变STRING阈值从0.4到0.5会从根本上改变PPI网络拓扑（边数可能减少50%），从而改变下游所有结果。而改变频率阈值从80%到70%只是重新分类标签，不会改变底层计算的任何结果。

3. **统计基础差异**：频率阈值基于Bootstrap置信区间，有明确的统计含义（"该靶点在95%的参数组合中显著"），而STRING=0.4没有类似的统计依据。

**一句话反驳审稿人**：
> "The quadrant classification is merely a descriptive label for presentation; the complete frequency and topological data for all targets and pathways are provided in Supplementary Tables 2-3, allowing readers to assess robustness at any cutoff."

## 核心发现记录（MVP v2 验证后）

> **记录日期**: 2026-04-24  
> **实验批次**: MVP v2（36个参数组合，Prob=[0.0,0.05,0.1]）  
> **记录目的**: 固定关键发现，避免在后续分析中被遗忘或误读

### 发现一：GO层级验证揭示"氧化应激响应"GO term的完全缺席

**现象**：
- 使用 goatools 从 GO:0006979 (response to oxidative stress) 提取全部后代节点，共 **28 个精确 GO terms**
- 在 MVP v2 的 36 个参数组合富集结果中，**0 条通路属于这 28 个 GO terms**
- 这意味着：富集到的 GO terms（如 MAPK cascade, receptor tyrosine kinase signaling 等）**不是**"氧化应激响应"的直接后代

**生物学含义**：
- 草莓叶活性成分不是直接激活"细胞对氧化应激的响应"这个生物学过程
- 而是通过调控更上游的通用信号节点（MAPK/RTK/TNF等），**间接影响**氧化应激平衡
- 与药理学认知一致：儿茶素、原花青素等天然产物是多靶点弱调控，通过网络效应发挥作用

**对叙事的冲击**：
- 传统套路"化合物→靶点→氧化应激通路→抗氧化结论"在本数据中**不成立**
- 需要升级为"化合物→多靶点→信号网络主干道→多效应输出（含氧化应激）"的网络调控叙事

### 发现二：关键词匹配存在系统性误标记（'ROS'子串陷阱）

**问题定位**：
```python
# 旧方法（有bug）
is_ox = any(kw.lower() in term.lower() for kw in ANTIOXIDANT_KEYWORDS)
```
- 关键词 `'ROS'` 匹配了 `tyrosine`（ty**ros**ine）、`atherosclerosis`（atheroscler**os**is）、`necrosis`（necr**os**is）、`prostate`（p**ros**tate）
- 在 17 条被旧方法标记为"氧化应激"的通路中，**11 条（65%）是误标记**

**误标记列表**：
| 通路名称 | 误匹配来源 |
|---------|-----------|
| transmembrane receptor protein tyrosine kinase signaling pathway | ty**ros**ine |
| peptidyl-tyrosine modification | ty**ros**ine |
| protein tyrosine kinase activity | ty**ros**ine |
| Fluid shear stress and atherosclerosis | atheroscler**os**is |
| Lipid and atherosclerosis | atheroscler**os**is |
| Prostate cancer | p**ros**tate |
| tumor necrosis factor receptor binding | necr**os**is |

**正确匹配的只有 6 条**：MAPK相关4条 + AGE-RAGE 1条 + IL-17 1条

**解决方案**：
- GO terms → 用 GO:0006979 后代层级验证（最可靠）
- KEGG/Reactome → 用 curated 已知列表 + 单词边界关键词（`\bros\b`）
- **禁止**使用子串匹配判断通路属性

### 发现三：稳健靶点的真实身份（Tier 1 + Tier 2 双层级）

**Tier 1: 绝对稳健靶点（9个）—— 所有参数组合的交集**

在所有36个参数组合中**100%出现**的靶点：
> KDR, TNF, STAT3, SRC, PTGS2, MMP2, BCL2, MET, KIT

- 这些靶点不受任何参数选择的影响，是跨参数不可压缩的核心节点
- 富集分析仍捕获PI3K-Akt、MAPK、Rap1三条信号主干通路（Adjusted P < 10⁻⁸）
- 作为方法学验证的"底线"——即使最严格标准，核心信号依然稳定

**Tier 2: 核心稳健靶点（33个）—— Q1象限（高频+高拓扑）**

在频率中位数（≥33%）和Degree中位数分割下进入Q1象限的靶点：
- **出现频率 97.2%**（35-36/36个组合）：TNF, SRC, STAT3, KDR, BCL2, PTGS2, MMP2, MET, KIT, IL2, FGFR1, FGF1, CA9, etc.
- **出现频率 66.7%**（24/36个组合）：EGFR, APP, MMP9, STAT1, ERBB2, HIF1A, ESR1, FLT1, MMP1, MAPK14, etc.
- **出现频率 33.3-63.9%**（12-23/36个组合）：PGF, ABCB1, ESR2, MMP7, MMP14, CDK1, MAOB, ABCG2, FGF2, HSP90AA1

> **注**：Tier 2包含Tier 1（9个是33个的子集），Tier 2在Tier 1基础上扩展至跨参数高频留存且维持高网络中心性的多效性枢纽。

**关键洞察**：
- 这些靶点全部是**多效性信号节点**（pleiotropic hubs），不是抗氧化专用基因
- TNF：炎症+凋亡+氧化应激交叉点
- SRC：RTK信号核心激酶
- STAT3：转录因子，炎症与细胞存活调控
- EGFR：生长因子受体，增殖与存活
- BCL2：凋亡调控核心
- PTGS2（COX-2）：炎症与氧化应激交叉

**结论**：靶点的稳健性恰恰来源于它们的**多效性**——它们是信号网络的"交通枢纽"，不是单一功能的"专线节点"

**真正稳定的通路**（频率>80%，平均排名靠前）：
| 通路 | 出现频率 | 平均排名 | 性质 |
|------|---------|---------|------|
| MAPK signaling pathway | 97.2% | 14.4 | 信号网络主干道 |
| transmembrane receptor protein tyrosine kinase signaling pathway | 97.2% | 8.6 | 受体信号上游 |

3. 氧化应激只是这些通路的**下游效应之一**，不是通路本身的定义属性

### 发现五：叙事重构的必要性与方向

**传统叙事（数据不支持）**：
> "草莓叶活性成分通过调控氧化应激通路发挥抗氧化作用"

**数据支持的叙事**：
> "草莓叶活性成分通过多靶点协同调控 MAPK/RTK/PI3K-Akt 等核心信号网络，这些网络作为细胞信号传导的'主干道'，与氧化应激、炎症反应、细胞凋亡等多种病理生理过程存在交叉调控。因此，草莓叶的抗氧化保护作用可能是通过间接调控这些上游网络节点，进而影响下游氧化应激平衡的协同网络效应。"

**方法学层面的叙事升级**：
1. **靶点优先**：靶点是主要发现（数学上稳健），通路是下游功能注释
2. **网络而非单一路径**：强调多通路协同，不强行归属单一功能
3. **层级清晰**：区分"信号网络主干道"（上游调控）与"效应输出"（下游结果）
4. **诚实面对局限**：明确说明数据中无直接的"氧化应激响应"GO term，避免过度解读

### 发现六：参数敏感性分析的方法学价值得到验证

**如果没有这套分析，会发生的错误**：
1. **Prob=0.2 陷阱**：会错误地得到仅13个靶点（CA基因劫持），得出完全不同的结论
2. **关键词误标记**：会把 tyrosine kinase 通路当成氧化应激通路，发表错误结论
3. **单一参数偏差**：如果只用 STRING=0.4/TopK=30，会遗漏其他参数下的稳健靶点

**这套方法的价值**：
- 揭示了网络药理学结果对参数选择的隐性依赖
- 提供了系统性的稳健性评估框架
- 阻止了错误结论的产生（CA劫持、关键词误匹配等）

> **决策背景**: MVP v2 验证后发现 GO:0006979 后代 term 完全缺席，旧关键词匹配存在 65% 误标记率

| 考量维度 | 出路一（坚持旧框架） | 出路二（完全转向） | 出路三（重构框架） |
|:---|:---|:---|:---|

| 审稿人风险 | 🔴 高（GO验证是硬伤） | 🟡 中（需解释转向） | 🟢 低（数据诚实） |
| 与原始目标距离 | 近 | 远 | 适中 |
| 方法学创新亮点 | 无 | 有 | ✅ 有（参数敏感性+GO层级验证） |
| 工作量 | 小 | 大 | 中等 |

**核心判断**：
1. 靶点稳健性（Tier 1: 9个绝对稳健 + Tier 2: 33个核心稳健）是**无懈可击的数学事实**，不需要改变
2. "氧化应激通路"这个分类标准本身有问题，**不是数据有问题**
3. 继续验证"氧化应激通路稳健性"等于在验证一个**错误的前提**
4. 出路三既保留了与氧化应激的关联（通过交叉调控论证），又诚实地面对了数据的限制

### 稳健靶点的完整定义

#### 1. 操作性定义（算法层面）

本研究采用**双层稳健性评估体系**，区分"绝对稳健"与"核心稳健"两个层级：

---

**Tier 1: 绝对稳健靶点（All-gradient Robust Targets）**

> **定义**：在所有参数组合中均进入 Top-K Hub 集合的靶点基因（出现频率 = 100%）。

**判定标准**：
```
Tier 1 = ∩(Top-K_i)  for i = 1, 2, ..., N
         （所有N个参数组合Top-K集合的交集）
```

**本数据结果**：9个靶点（KDR, TNF, STAT3, SRC, PTGS2, MMP2, BCL2, MET, KIT）

**论文角色**：方法学验证的"底线证明"——即使最严格的稳健性标准（所有组合均出现），核心信号通路依然稳定。

---

**Tier 2: 核心稳健靶点（Core Robust Targets）**

> **定义**：在参数扫描网格中，同时满足"跨参数高频留存"和"高拓扑重要性"的靶点基因。

**条件一：跨参数频率达标**  
采用数据驱动方式，以频率中位数作为分界：
- **高频**：频率 ≥ 频率中位数（本数据集为 33%）
- **低频**：频率 < 频率中位数

**条件二：拓扑重要性达标**  
在 PPI 网络中，该靶点的平均 Degree（连接度）不低于 Degree 中位数。

同时满足条件一和条件二 → **Q1 象限：核心稳健靶点（33个）**

**论文角色**：主要分析靶点集合——用于富集分析和通路解读。数量适中（33个），足以覆盖核心信号网络，同时避免边缘靶点噪音。

#### 2. 统计学定义（跨参数留存稳定性）

稳健靶点的本质特征是**跨参数梯度留存能力**，本研究将其量化为两个层级：

| 层级 | 定义 | 数量 | 本数据代表靶点 | 生物学意义 |
|:---|:---|:---:|:---|:---|
| **Tier 1: 绝对稳健** | 在所有参数组合中均进入 Top-K（频率=100%） | **9个** | KDR, TNF, STAT3, SRC, PTGS2, MMP2, BCL2, MET, KIT | 跨参数不可压缩的核心节点，不受任何阈值人为干扰 |
| **Tier 2: 核心稳健** | 频率 ≥ 中位数（≥33%）且平均Degree ≥ 中位数 | **33个** | 包含Tier 1全部9个，外加IL2, FGFR1, FGF1, EGFR, APP, MMP9, STAT1, ERBB2, HIF1A等24个 | 跨参数高频留存的高拓扑枢纽，覆盖核心信号网络 |

**层级关系**：Tier 1 ⊂ Tier 2，Tier 1是Tier 2的"硬核子集"。

**参数梯度特征**（以Tier 2靶点为例）：
- **Prob=0.0/0.05时**：几乎所有Tier 2靶点（≥90%）均稳定出现
- **Prob=0.1时**：约60%的Tier 2靶点仍稳定出现，其余因网络规模缩小（54靶点→Top-K竞争加剧）而边缘化
- **Prob=0.2时**：进入富集失效区间（见下方排除理由），不纳入稳健性评估

**关于 Prob=0.2 的排除理由**：
> Prob=0.2时仅保留13个预测靶点，其中12个为碳酸酐酶（CA）家族成员，形成"基因家族劫持"现象——富集分析完全被CA家族的GO功能注释主导，氧化应激相关通路完全消失。此时Top-K（25-40）几乎取全部靶点，丧失了网络拓扑排序的意义。该参数已进入**富集失效区间**，故不纳入稳健性评估网格。

**核心判据**：一个靶点是否稳健，不取决于它在某一最优参数组合中的表现，而取决于它**在参数合理波动范围内的留存稳定性**。

#### 3. 生物学定义（网络药理学语境）

从生物学角度，稳健靶点具有以下特征：

1. **多效性信号枢纽（Pleiotropic Hub）**  
   稳健靶点不是单一通路的功能节点，而是多个信号通路的交汇点。例如：
   - TNF：炎症 + 凋亡 + 氧化应激交叉点
   - SRC：RTK 信号核心激酶
   - STAT3：转录调控，连接细胞存活与炎症
   - EGFR：生长因子信号，调控增殖与分化

2. **网络拓扑核心性**  
   在 PPI 网络中表现为高 Degree（连接数多）和高 Betweenness（信息流经的关键桥梁）。这意味着：即使移除部分边缘节点，这些靶点仍然处于网络中心，不会被挤出核心子网络。

3. **参数无关性**  
   其网络核心地位不依赖于特定的 SwissTarget 概率阈值或 STRING 置信度阈值。无论概率阈值是 0.0（纳入 282 个靶点）还是 0.1（仅纳入 54 个靶点），这些靶点都在 Degree 排名的前 25-40 名之内。

#### 4. 稳健靶点与传统靶点的本质区别

| 维度 | 传统靶点筛选 | 稳健靶点筛选 |
|:---|:---|:---|
| **参数设置** | 单一固定参数（如 Prob=0.05, STRING=0.4） | 多参数组合扫描（如 Prob=[0.0,0.05,0.1], STRING=[0.3,0.4,0.5,0.7]） |
| **筛选逻辑** | "这组参数下哪些靶点进入 Top-K？" | "哪些靶点在所有合理参数下都进入 Top-K？" |
| **结果特征** | 靶点集合依赖参数选择，换参数结果可能完全不同 | 靶点集合跨参数一致，不受单一参数组合主导 |
| **假阳性风险** | 高（可能包含参数特异性噪音） | 低（经过多参数交叉验证） |
| **生物学可信度** | 中等（仅验证一次） | 高（跨条件反复验证） |

#### 5. 稳健靶点的定量标准（本研究采用）

```
稳健靶点判定流程：

Step 1: 参数扫描
  └─ 运行 N 个参数组合（本研究 N=36）
  └─ 记录每个靶点在每次组合中的出现情况

Step 2: 频率计算
  └─ 频率 = 出现次数 / N

Step 3: 拓扑重要性计算
  └─ 平均 Degree = 该靶点在每次出现时的 Degree 均值
  └─ 平均 Betweenness = 中介中心性均值

Step 4: 象限分类（数据驱动）
  └─ 频率中位数分割 → 高频 / 低频
  └─ Degree 中位数分割 → 高拓扑 / 低拓扑
  └─ Q1（高频+高拓扑）= 核心稳健靶点

Step 5: 双层级稳健靶点判定
  └─ Tier 1（绝对稳健）：所有参数组合的 Top-K 交集（频率=100%）
       └─ 本研究：9个靶点（KDR, TNF, STAT3, SRC, PTGS2, MMP2, BCL2, MET, KIT）
       └─ 用途：方法学底线验证，证明最严格标准下核心通路仍稳定
  └─ Tier 2（核心稳健）：Q1象限（频率≥中位数 AND 平均Degree≥中位数）
       └─ 本研究：33个靶点（包含Tier 1全部9个）
       └─ 用途：主要富集分析和通路解读
```

#### 6. 一句话定义（可直接用于论文）

> **稳健靶点是指在网络药理学参数合理波动范围内，跨多组筛选条件持续保留于核心 PPI 子网络、且具有高拓扑重要性的多效性信号枢纽基因。其出现不依赖于特定的概率阈值或网络置信度设定，反映了化合物-靶点-通路关联的真实生物学稳定性。**

### 论文可直接使用的关键论述段落

**论述一：参数敏感性分析的必要性（Introduction/Discussion适用）**

> "网络药理学分析的结果高度依赖参数阈值的选择。本研究通过预实验发现，当SwissTarget概率阈值设定为0.2时，预测靶点数量锐减至13个，富集分析完全被碳酸酐酶基因家族主导，氧化应激相关通路完全消失；而当概率阈值设定为0.05时，核心靶点稳定映射到MAPK/RTK/PI3K-Akt等信号网络主干道。这一发现凸显了系统性参数稳健性分析的必要性——仅基于单一参数组合得出的结论可能存在严重的参数依赖性偏差。"

**论述二：靶点稳健性的定义（Methods适用）**

> "本研究采用双层稳健性评估体系识别稳健靶点。Tier 1绝对稳健靶点定义为在所有参数组合中均进入Top-K Hub集合的靶点（频率=100%），代表跨参数不可压缩的核心节点；Tier 2核心稳健靶点采用二维评价体系筛选——同时满足跨参数高频留存（频率≥中位数）和网络高拓扑重要性（平均Degree≥中位数），代表在参数合理波动范围内稳定保留于核心PPI子网络的多效性信号枢纽。Prob=0.2时因靶点过少（13个）导致富集失效（碳酸酐酶家族劫持），故排除于评估网格之外。"

**论述三：GO层级验证的方法学创新（Methods/Discussion适用）**

> "传统网络药理学研究常采用关键词匹配法筛选氧化应激相关通路，但本研究发现该方法存在系统性误标记风险——如关键词'ROS'的子串匹配可错误地将tyrosine kinase、atherosclerosis等通路标记为氧化应激相关。为解决这一问题，本研究引入Gene Ontology层级验证策略，以GO:0006979（response to oxidative stress）为根节点，提取其全部后代术语作为'直接氧化应激响应通路'的黄金标准，从而避免了关键词匹配的假阳性偏倚。"

**论述四：三级通路分类体系（Results/Discussion适用）**

> "基于GO层级验证结果，本研究建立了三级通路分类体系：（1）直接氧化应激响应通路（GO:0006979后代术语），在本数据中未检出；（2）交叉调控通路（如AGE-RAGE signaling、IL-17 signaling），已知与氧化应激存在功能交叉；（3）信号网络主干道（如MAPK/RTK/PI3K-Akt），为核心信号转导通路。这一分类体系揭示了草莓叶抗氧化作用的潜在机制：并非直接激活氧化应激响应通路，而是通过调控上游信号网络主干道，间接影响下游氧化应激平衡。"

**论述五：从'单一通路'到'网络调控'的叙事转变（Discussion适用）**

> "传统网络药理学叙事常将富集到的通路直接等同于药物的作用机制（如'通过MAPK通路抗氧化'），但本研究的数据提示，这种简化可能存在过度解读的风险。MAPK/RTK/PI3K-Akt等通路是细胞信号网络的'主干道'，调控炎症、凋亡、增殖等多种细胞命运，氧化应激只是其下游效应之一。因此，更准确的表述应为：草莓叶活性成分通过多靶点协同调控核心信号网络，进而间接影响包括氧化应激在内的多种病理生理过程。"

### 参数网格细化决策（2026-04-24）

**决策背景**：
- MVP v2 初始参数网格为 36 组合（Prob=3 × STRING=4 × TopK=3 × Pvalue=1）
- 靶点稳健性分析已完成，Q1 核心稳健靶点 33 个
- 但 STRING 阈值从 0.3 跳到 0.4 再到 0.5，中间缺少过渡点，可能遗漏关键敏感性信息

**决策内容**：细化取值密度，将靶点层参数网格从 36 组合扩展至 72 组合

#### 细化后的靶点层参数网格

| 参数 | 原取值 | 细化后取值 | 新增点 | 理由 |
|:---|:---|:---|:---|:---|
| **P_prob** | [0.0, 0.05, 0.1] | [0.0, 0.05, 0.1] | 无 | 已覆盖有效区间，无需细化 |
| **P_string** | [0.3, 0.4, 0.5, 0.7] | [0.3, 0.35, 0.4, 0.45, 0.5, 0.7] | **0.35, 0.45** | 观察 0.3→0.5 过渡区的网络稀疏化拐点 |
| **K_top** | [25, 30, 40] | [25, 30, 35, 40] | **35** | 覆盖 30 附近的 Hub 筛选敏感性 |
| **P_pvalue** | [0.01] | [0.01] | 无 | 靶点筛选不受 Pvalue 影响，固定 |

**新网格总计**：3 × 6 × 4 × 1 = **72 组合**（原 36 组合）

#### 细化 STRING 阈值的核心价值：寻找网络稀疏化"拐点"

原网格的问题：
```
STRING=0.3: 758 条边
STRING=0.4: 758 条边  ← 从0.3到0.4几乎无变化？
STRING=0.5: 532 条边  ← 从0.4到0.5骤降 226 条
STRING=0.7: 255 条边  ← 继续下降
```

**疑问**：0.3→0.4 之间是否真的无变化？0.4→0.5 的骤降是从哪个具体阈值开始的？

增加 0.35 和 0.45 后，可以精确观察：
```
STRING=0.30: 758 条边
STRING=0.35: ??? 条边  ← 新增：观察是否开始下降
STRING=0.40: 758 条边
STRING=0.45: ??? 条边  ← 新增：观察下降是否已经开始
STRING=0.50: 532 条边
STRING=0.70: 255 条边
```

**预期发现**：
- 如果 0.35 时边数已开始下降 → 说明网络对 0.3-0.4 区间的阈值变化敏感
- 如果 0.45 时边数仍接近 758 → 说明 0.5 才是真正的"断崖点"
- 这种"拐点"信息对理解 PPI 网络的阈值敏感性具有方法学价值

#### 细化 Top-K 的价值：验证 Hub 筛选数量的边际效应

原网格 TopK=30 vs 40，跳跃较大。增加 TopK=35 后：
- 可以观察 30→35→40 的渐进变化
- 验证核心靶点（TNF/SRC/STAT3）是否在 30-40 范围内始终位于 Top 排名
- 识别"刚好被挤出 Top-30 但进入 Top-35"的潜在重要靶点

#### 关于 P_pvalue 的处理决策

**结论**：靶点筛选阶段**不扫描 P_pvalue**。

理由：
1. P_pvalue 只影响富集分析的"显著性判断"，不影响靶点筛选（靶点筛选在富集之前完成）
2. 核心靶点的 Degree 排序和 Top-K 选择与 P_pvalue 无关
3. P_pvalue 的扫描价值在通路层面，而非靶点层面

**P_pvalue 的后续处理**：
- 靶点分析完成后，仅对**核心参数组合**（P=0.05, STRING=0.4, TopK=30）做三标准验证（P=0.001, 0.01, 0.05）
- 验证核心通路（MAPK/RTK/PI3K-Akt）的显著性是否受 Pvalue 标准影响
- 最低成本防御审稿人质疑

#### 分阶段执行计划

**Phase 1（靶点层 72 组合）**：
- 参数：Prob[3] × STRING[6] × TopK[4] × Pvalue[1] = 72 组合
- 内容：筛选靶点 → 构建 PPI 网络 → Degree 排序 → 取 Top-K
- **不做富集分析**（节省时间）
- 预计时间：10-15 分钟
- 预期产出：新的靶点稳健性结果，验证 Q1 靶点在更精细网格中是否仍然稳健

**Phase 2（P_pvalue 最低成本验证）**：
- 仅对 1 个核心组合跑 3 个 Pvalue 标准
- 预计时间：30 秒
- 预期产出：核心通路在三标准下的显著性对比
