## 传统方法: Degree Top-30 筛选

### 筛选方法

```
PPI 网络 → 按 degree 降序排列 → 取 Top-30 → 富集分析
```

### 传统方法定义

- **筛选依据**: 节点的 degree（连接数）
- **Top-K**: K = 30
- **假设**: 高度连接的节点（Hub Node）在生物学上更重要

## 备注

- 富集分析使用 `gseapy.enrichr`，基因集 `KEGG_2021_Human`
- P-value 阈值: 0.05（显著）
- 氧化应激通路筛选: 关键词匹配
- EF = (k/n) / (N/M)，其中 M=20500（人类蛋白编码基因总数）
- STRING 数据库 combined_score 阈值: 0.4
