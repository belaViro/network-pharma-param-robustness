# Stage 3: 靶点合并去重

> **注意**: 本文档记录了早期运行结果（109 个靶点）。后续发现 SwissTarget 输出中存在多基因条目（如 `PSEN2 PSENEN NCSTN`），修正拆分后最新结果为 **116 个靶点**。详见 [`数据修正记录.md`](数据修正记录.md)。

## 概述

合并所有活性成分的靶点预测结果，进行去重和概率过滤。

## 关键修复

**重要**: 初始版本遗漏了 `Probability > 0` 的过滤，与原论文方法不一致。
- 原论文明确说明: "Probability > 0，删除重复值"
- 本文档记录: 过滤前 282 个靶点 → 过滤后 **109 个靶点**（修正拆分后最新为 **116**）

## 处理逻辑

1. **合并**: 合并5个成分的靶点CSV文件
2. **去重**: 同一靶点出现在多个成分时，保留**概率最高**的记录
3. **过滤**: 只保留 **Probability > 0** 的靶点

## 去重逻辑说明

合并去重逻辑:
1. 同一靶点可能出现在多个成分中
2. 保留**概率最高**的成分作为来源
3. 过滤 **Probability > 0** 的靶点

这意味着:
- 如果靶点A在Catechin中概率=1.0，在Procyanidin B1中概率=0.5
- 最终记录: A, Catechin, 1.0
- 即使Procyanidin B1对该靶点也有贡献，也会被标记为Catechin来源
