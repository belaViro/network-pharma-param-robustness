# 数据格式问题修正记录

## 问题发现

在生成韦恩图时，发现 `merged_targets.csv` 中有2条记录的 `Target_Gene` 字段包含多个基因（用空格分隔），而非单一基因名：

| Target_Gene | Source_Compound | Probability |
|-------------|-----------------|-------------|
| PSEN2 PSENEN NCSTN APH1A PSEN1 APH1B | Trehalose | 0.109946 |
| GABRA1 GABRB2 GABRG2 | Catechin | 0.097875 |

这导致统计数字不准确，需要进行拆分处理。

## 问题原因

SwissTargetPrediction 原始输出中，某些靶点预测结果以空格分隔的格式将多个基因符号写入同一单元格。

## 处理方案

修改 `stage3_merge_targets.py`，在数据合并后将多基因条目拆分为独立行：

```python
# 拆分多基因条目 (如 "PSEN2 PSENEN NCSTN" -> 多行)
multi_gene_mask = merged_df["Target_Gene"].str.contains(" ", na=False)
if multi_gene_mask.any():
    # 拆分逻辑...
```
