# 遇到的问题

## 1. net::ERR_NO_SUPPORTED_PROXIES 错误

**问题描述**：
运行 `automate_swiss_target_playwright.py` 时出现以下错误：

```
执行失败 (尝试 1/3): Page.goto: net::ERR_NO_SUPPORTED_PROXIES at https://www.swisstargetprediction.ch/
```

**根本原因**：
浏览器启动参数中设置了冲突的代理选项：
```python
'--disable-proxy-server',
'--proxy-server="direct://"',
```

这些参数与你 Windows 系统的代理设置冲突，导致浏览器无法正常连接。

**解决方案**：
移除冲突的代理参数，修改 `setup_browser()` 方法：

```python
self.browser = self.playwright.chromium.launch(
    headless=False,
    args=[
        '--disable-blink-features=AutomationControlled',
        '--no-sandbox',
        '--disable-dev-shm-usage',
    ]
)
```

**如果问题仍然存在**：
- 方法1：关闭 Windows 系统代理
  - 设置 → 网络和 Internet → 代理 → 关闭"手动代理设置"
- 方法2：运行前清除环境变量
  ```bash
  set HTTP_PROXY=
  set HTTPS_PROXY=
  python automate_swiss_target_playwright.py
  ```
