# V2 稳三区投稿计划

> 项目：网络药理学靶点筛选的参数稳健性分析  
> 版本目标：V2 稳三区版  
> 创建日期：2026-04-27  
> 当前定位：方法学框架 + 草莓叶抗氧化相关网络药理学案例研究

## 1. 一句话结论

当前项目已经具备投稿基础，但还不能直接按二区稿包装。V2 版的目标不是强行证明草莓叶抗氧化机制，而是把论文定位为：

> 提出并验证一种用于网络药理学靶点筛选的参数稳健性分析框架，量化传统固定参数流程中被忽略的结果不确定性，并以草莓叶活性成分为案例展示该框架如何识别跨参数稳定的核心靶点和信号通路。

V2 完成后，建议主投 PLOS ONE 或 BMC Complementary Medicine and Therapies，Scientific Reports 和 Frontiers in Pharmacology 可作为冲刺选项，但不作为稳妥目标。

## 2. V2 版投稿边界

### 2.1 V2 做什么

- 固定当前主线：参数敏感性分析 + 稳健靶点识别 + 稳健通路验证。
- 完成外部数据库验证，降低“只是在内部指标上自洽”的审稿风险。
- 统一所有结果数字和术语，消除 README、旧进度文档、输出结果之间的不一致。
- 整理可复现材料，使审稿人能够复跑主要分析。
- 写成方法学 case study，而不是强机制验证论文。

### 2.2 V2 不做什么

- 不加入 GNN、BioBERT 作为主线。它们目前是探索记录，不进入主文。
- 不声称已经完成湿实验验证。
- 不把草莓叶的抗氧化作用写成已被证实的药理机制。
- 不把 Bootstrap 不确定性量化作为主贡献，除非后续确实补充完整 CI 结果。
- 不冲 Journal of Ethnopharmacology 或 Phytomedicine 作为首投。

### Phase 3：消融和对比分析

目标：证明稳健靶点筛选不是简单重复固定参数 Top-K。

对比组：

| 组别 | 定义 | 用途 |
|---|---|---|
| Fixed TopK | 文献默认或传统参数，如 STRING 0.4、TopK 30 | baseline |
| Best Parametric | 单一参数组合中表现最好的 TopK 集合 | 展示单点最优风险 |
| Q1 Robust | 高频 + 高标准化 Degree 的核心稳健靶点 | 主方法 |
| Tier 1 | 所有参数组合均出现的绝对稳健靶点 | 最严格子集 |

指标：

- 靶点数量。
- 与 Fixed TopK 的重叠率。
- 显著通路数。
- signaling backbone 数量。
- cross-talk pathway 数量。
- avg EF。
- min adjusted p value。
- 外部数据库 overlap 和 p value。

建议输出：

- `src/outputs/sensitivity/ablation_comparison.csv`
- `src/outputs/sensitivity/figures/fig_ablation_comparison.png`
- `docs/ablation_v2.md`

验收标准：

- 能清楚说明 Q1/Tier1 的优势是“稳健性和可重复性”，而不是单纯追求最多通路。

### Phase 5：论文结构和写作

建议标题：

> A parameter-robustness framework for target prioritization in network pharmacology: a case study of strawberry leaf compounds and oxidative-stress-related signaling

备选中文题目：

> 网络药理学靶点筛选的参数稳健性分析框架：以草莓叶活性成分氧化应激相关信号网络为例

建议结构：

1. Introduction
   - 网络药理学广泛使用固定阈值。
   - 参数选择缺乏系统论证。
   - 现有研究常把单次参数结果直接解释为机制。
   - 本研究提出参数稳健性框架。

2. Materials and Methods
   - Compound and target prediction.
   - Disease gene collection.
   - PPI network construction.
   - Parameter grid design.
   - Robust target definition.
   - Pathway enrichment and classification.
   - External validation.
   - Statistical analysis.

3. Results
   - Baseline network pharmacology result.
   - Parameter grid reveals stable and unstable regions.
   - Robust target prioritization identifies Q1 and Tier 1 targets.
   - Robust targets map to signaling backbone pathways.
   - External validation supports biological relevance.
   - Fixed-parameter analysis can overstate or distort pathway interpretation.

4. Discussion
   - Why parameter robustness matters.
   - Why direct oxidative stress GO terms are absent.
   - Interpretation as upstream signaling network modulation.
   - Methodological value and generalizability.
   - Limitations.

5. Conclusion
   - The framework improves transparency and reliability of network pharmacology target prioritization.

## 6. 目标期刊策略

### 6.1 稳妥目标

| 期刊 | 投稿定位 | V2 适配度 |
|---|---|---|
| PLOS ONE | sound science + reproducible computational method | 高 |
| BMC Complementary Medicine and Therapies | herbal/natural product computational case study | 中高 |
| MethodsX | reproducible method/protocol | 高，但分区偏低 |

### 6.2 冲刺目标

| 期刊 | 需要额外补强 | 风险 |
|---|---|---|
| Scientific Reports | 多数据库验证 + 图表成熟 + 方法泛化表述 | 中 |
| Frontiers in Pharmacology | 外部验证充分，最好加分子对接 | 中高 |

### 6.3 暂不建议

| 期刊 | 原因 |
|---|---|
| Journal of Ethnopharmacology | 缺少湿实验或更强民族药理学证据链 |
| Phytomedicine | 对药理机制和实验验证要求更高 |

投稿前必须用学校认可的中科院分区表重新核验分区，不在论文中写分区。

## 8. 风险和应对

| 风险 | 严重度 | 应对 |
|---|---|---|
| 外部数据库验证不显著 | 高 | 降低机制结论，强调方法学框架 |
| Q1/Tier1 与固定参数差异不大 | 中 | 强调稳健性不是追求极值，而是避免单参数偏差 |
| direct_ox_count 为 0 被质疑 | 中 | 主动解释为“未检出直接氧化应激响应 GO 子树”，转向上游信号主干道 |
| 只有一个 case study | 高 | 在 Limitations 中承认，V3 再扩展多案例 |
| 旧文档数字混乱 | 高 | 投稿前统一或归档历史文档 |
| MethodsX 分区偏低 | 中 | 作为保底，不作为首选 |

## 11. 最终判断

V2 的成功标准不是“达到二区水平”，而是“形成一篇逻辑闭环、证据透明、风险可控的三区稿”。当前项目已经完成最难的工程和主分析部分，V2 的关键在于补外部验证、统一口径、重新组织论文叙事。

如果 V2 执行到位，稳三区是现实目标；如果在 V2 基础上增加多案例泛化和分子对接，可进入 V3 冲二区路线。
