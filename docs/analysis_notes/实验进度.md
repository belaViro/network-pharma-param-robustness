## 一、研究目标

本项目旨在建立一套**带不确定度量化的网络药理学分析框架**，解决传统网络药理学中参数选择主观性强、结果稳健性未知的问题。

**核心科学问题**: 当 SwissTarget 置信度阈值、STRING 网络截断阈值、富集显著性阈值、Hub 基因数量等关键参数发生变化时，最终鉴定的靶点和通路有多可靠？

### Stage 7: Hub 基因筛选 (Degree Centrality)

**方法**: 按 Degree 降序排列，取前 K 个基因作为 Hub 基因集

**核心参数: TOP_K_HUB**

`TOP_K_HUB` 是连接 Stage 6 (PPI网络) 和 Stage 8 (富集分析) 的关键桥梁参数，直接决定进入富集分析的基因数量。

**参数取值范围** (参数敏感性分析中扫描):

| K 值 | 生物学意义 | 适用场景 |
|------|-----------|---------|
| **10** | 最严格的 Hub 筛选，仅保留核心中的核心 | 聚焦最关键靶点 |
| **20** | 较严格的筛选 | 平衡核心性与覆盖度 |
| **30** (默认) | 传统网络药理学常用值 | 文献标准做法 |
| **50** | 较宽松的筛选 | 提高通路覆盖度 |

**K 值对结果的影响机制**:

```
K 增大 → Hub基因集变大 → 富集分析输入变大 → 显著通路可能增多
       → 但特异性下降 → 可能引入噪声通路

K 减小 → Hub基因集变小 → 特异性提高 → 但可能遗漏重要通路
       → 统计检验力下降 → 通路数可能减少
```

**当前结果** (K=30 时):
- 输入基因: 30
- 显著 KEGG 通路: 20 条
- 氧化应激相关通路: 6 条 (30%)

**状态**: ✅ 已完成

## 四、核心创新: 参数敏感性分析与Bootstrap不确定性量化

### 4.1 框架概述

本研究采用 **参数敏感性分析 (Sensitivity Analysis, SA)** 与 **Bootstrap 不确定性量化 (Uncertainty Quantification, UQ)** 相结合的方法，系统评估网络药理学分析结果的稳健性。

**解决的问题**:
- 传统网络药理学使用**固定参数**（如 Prob≥0, STRING≥0.4, P<0.01, K=30），结果的主观性强
- 换一组参数，结果可能完全不同，但研究者不知道"这个结果有多可靠"
- 本框架不仅回答"换参数结果怎么变"，还回答"这个结果我有多大把握相信"

### 4.2 参数敏感性分析 (SA)

**方法**: 系统扫描四维参数空间的所有组合

**扫描参数**:

| 参数 | 符号 | 取值范围 | 生物学意义 |
|------|------|---------|-----------|
| SwissTarget Probability 阈值 | `prob_th` | 0.0, 0.05, 0.1, 0.2, 0.3 | 靶点预测置信度 cutoff |
| STRING Combined Score 阈值 | `string_th` | 0.0, 0.3, 0.4, 0.5, 0.7 | PPI 网络边可信度 cutoff |
| 富集分析 P-value 阈值 | `pval_th` | 0.01, 0.05 | 统计显著性 cutoff |
| **Hub 基因数量** | **`top_k`** | **10, 20, 30, 50** | **核心靶点集合大小** |

**参数组合总数**: 5 × 5 × 2 × 4 = **200 种组合**

**每个组合执行**:
1. Probability 过滤 → 保留高置信度靶点
2. STRING Score 过滤 → 构建 PPI 子网络
3. Degree 排序 → 取 Top-K Hub 基因
4. 富集分析 → 统计显著通路和氧化应激通路

### 4.3 Bootstrap 不确定性量化 (UQ)

**方法**: 对每个参数组合做有放回重采样

**流程**:
1. 从过滤后的靶点列表中有放回抽取同等数量样本
2. 去重后得到 Bootstrap 样本
3. 对 Bootstrap 样本执行完整分析流程（PPI → Hub → 富集）
4. 重复 N=100 次

**统计量计算**:
- **Bootstrap 均值**: 100 次结果的平均值（点估计的稳健替代）
- **95% 置信区间**: 2.5% 和 97.5% 分位数
- **CI 宽度**: 置信区间上限 - 下限（不确定性大小的度量）

### 4.4 综合可靠性评分

**可靠性评分模型**:

将参数敏感性分析得到的点估计与 Bootstrap 不确定性量化的置信区间结合，构建综合可靠性评分：

```
reliability_score = (ox_mean / ox_max) × 0.6 + (1 - CI_width / CI_max) × 0.4
```

- **氧化应激均值权重 60%**: 结果要"好"（发现足够多的氧化应激通路）
- **CI 窄度权重 40%**: 结果要"稳"（置信区间窄，不确定性低）

**综合评分模型** (最终推荐):

```
composite_score = ox_norm × 0.35 + total_norm × 0.15 + ef_norm × 0.15 + reliability_score × 0.35
```

## 五、关键参数详解: TOP_K_HUB

### 5.1 为什么 TOP_K_HUB 很重要

`TOP_K_HUB` 是网络药理学中最具主观性的参数之一：

- 文献中常见取值: 10, 20, 30, 50, 甚至 100
- 不同 K 值直接导致不同的 Hub 基因集 → 不同的富集结果
- 但很少有研究系统评估 K 值选择对结果的影响

### 5.2 TOP_K_HUB 在本项目中的定位

`TOP_K_HUB` 作为第 4 个扫描参数纳入参数敏感性分析框架，是本项目的**差异化创新点**：

> 已有研究扫描了 Probability 和 STRING Score，但几乎没有人把 Hub 基因数量 K 也纳入参数敏感性分析。

### 5.3 TOP_K_HUB 的影响预期

| K 值 | 预期影响 |
|------|---------|
| K=10 | 最保守，仅最核心靶点，通路数可能最少但特异性最高 |
| K=20 | 较保守，平衡核心性和覆盖度 |
| K=30 | 传统默认值，文献对标 |
| K=50 | 较宽松，可能发现更多通路但噪声增加 |

**参数敏感性分析的价值**: 不预设"K=30 最好"，而是让数据说话——哪个 K 值在"高氧化应激通路数"和"低不确定性"之间取得最优平衡。
