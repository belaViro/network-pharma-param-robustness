# SwissTargetPrediction 自动化靶点预测工作流

## 1. 概述

本工作流实现从分子名称到靶点预测结果的**全自动化批量处理**，包含两个核心阶段：

```
分子名称/ID
    │
    ▼ Stage 1
PubChem API 查询（获取 SMILES）
    │
    ▼ Stage 2
SwissTargetPrediction 靶点预测（下载 CSV）
```

> 未来扩展方向：交叉分析（肥胖靶点）→ STRING PPI 网络 → 通路富集分析 → 分子对接

## 2. 架构设计

### 2.1 核心设计原则

| 原则 | 说明 |
|------|------|
| **高内聚** | 每个模块只做一件事（connectors 只管连接，workers 只管执行） |
| **低耦合** | 模块间通过 dataclass/dict 传递数据，不直接依赖彼此内部状态 |
| **可测试** | 每个 connector、每个 worker 都能独立测试 |
| **可插拔** | 想跳过某个 Stage？替换对应 pipeline 文件即可 |

### 2.2 流水线并行策略

采用**两阶段流水线并行**：

| 阶段 | 任务 | 并行方式 | 原因 |
|------|------|----------|------|
| Stage 1 | PubChem API 查询 | `ThreadPoolExecutor` | HTTP I/O 密集型，线程开销低 |
| Stage 2 | Swiss 靶点预测 | `ProcessPoolExecutor` | Playwright 浏览器需独立进程 |

```
输入: ["Aspirin", "Ibuprofen", ...]  (N 个分子)

Stage 1 (ThreadPool, N 线程并发):
  Aspirin     → PubChem API → SMILES_A
  Ibuprofen   → PubChem API → SMILES_B
  ...

  ↓ 全量完成后

Stage 2 (ProcessPool, M 进程并发, M = min(4, CPU核数)):
  SMILES_A → Swiss 浏览器 → targets_A.csv
  SMILES_B → Swiss 浏览器 → targets_B.csv
  ...
```

## 3. 模块设计

### 3.1 Stage 1 — PubChem 查询

**Connector**：`src/connectors/pubchem.py`

```python
class PubChemClient:
    def get_compound_by_name(self, name: str) -> List[Dict]: ...
    def get_compound_by_smiles(self, smiles: str) -> List[Dict]: ...
```

**Worker**：`src/workers/pubchem_worker.py`

```python
def fetch_smiles(molecule_name: str) -> Dict:
    """根据分子名称从 PubChem 获取 SMILES"""
    client = PubChemClient()
    results = client.get_compound_by_name(molecule_name)
    if results and results[0].get("smiles"):
        return {"name": molecule_name, "smiles": results[0]["smiles"], "status": "成功"}
    return {"name": molecule_name, "smiles": None, "status": "未找到"}
```

**Pipeline**：`src/pipeline/stage1_fetch.py`

```python
def stage1_fetch_all(molecule_names: List[str]) -> List[Dict]:
    with ThreadPoolExecutor(max_workers=len(molecule_names)) as executor:
        futures = {executor.submit(fetch_smiles, name): name for name in molecule_names}
        for future in as_completed(futures):
            result = future.result()
            results.append(result)
    return results
```

### 3.2 Stage 2 — Swiss 靶点预测

**Connector**：`src/connectors/swiss_target.py`

```python
@dataclass(frozen=True)
class SwissTargetConfig:
    url: str = "https://www.swisstargetprediction.ch/"
    smiles: str = "CCC[C@H]1CCCCN1"
    organism: str = "Homo_sapiens"
    timeout: int = 15000

class SwissTargetPredictor:
    def run(self, smiles: str, organism: str = "Homo_sapiens", max_retries: int = 3) -> str:
        """运行完整流程，返回 CSV 文件路径"""
        ...
```

**Worker**：`src/workers/swiss_worker.py`

```python
def predict_target(smiles: str, download_path: str, organism: str = "Homo_sapiens") -> Dict:
    """单进程 Swiss 靶点预测 worker"""
    predictor = SwissTargetPredictor(download_path=download_path)
    try:
        csv_path = predictor.run(smiles=smiles, organism=organism)
        return {"smiles": smiles, "status": "成功", "csv": csv_path}
    except Exception as e:
        return {"smiles": smiles, "status": f"错误: {e}", "csv": ""}
    finally:
        predictor.close()
```

**Pipeline**：`src/pipeline/stage2_predict.py`

```python
def stage2_predict_all(smiles_results: List[Dict], download_path: str, max_workers: int = None) -> List[Dict]:
    valid = [r for r in smiles_results if r["status"] == "成功"]
    with ProcessPoolExecutor(max_workers=max_workers or min(4, cpu_count())) as executor:
        futures = {executor.submit(predict_target, s, download_path): s for s in valid}
        for future in as_completed(futures):
            results.append(future.result())
    return results
```

### 3.3 流水线入口

**入口**：`scripts/run_pipeline.py`

```python
def run_pipeline(molecule_names: List[str], output_dir: str = None, max_workers: int = None) -> Dict:
    """完整流水线"""
    # Stage 1
    stage1_results = stage1_fetch_all(molecule_names)
    # Stage 2
    stage2_results = stage2_predict_all(stage1_results, output_dir, max_workers)
    # 生成报告
    return {"stage1_results": stage1_results, "stage2_results": stage2_results, "report_path": "..."}
```

## 4. 使用方式

```python
# 方式 1：从分子名称运行完整流水线
from scripts.run_pipeline import run_pipeline
run_pipeline(["Aspirin", "Ibuprofen", "Caffeine"])

# 方式 2：从 SMILES 直接运行 Stage 2（跳过 Stage 1）
from scripts.run_pipeline import run_from_smiles
run_from_smiles(["CC(=O)OC1=CC=CC=C1C(=O)O", "CC(C)Cc1ccc(cc1)C(C)C(=O)O"])

# 方式 3：分步调用
from src.pipeline import stage1_fetch_all, stage2_predict_all
stage1 = stage1_fetch_all(["Aspirin"])
stage2 = stage2_predict_all(stage1, "/path/to/output")
```

## 5. 并发配置

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| Stage 1 线程数 | `len(molecule_names)` | PubChem API 无频率限制，可全量并发 |
| Stage 2 进程数 | `min(4, cpu_count())` | 每个进程占用独立浏览器，4 个足够 |

### 反爬策略

- **Stage 1**：PubChem 对 API 查询友好，不需要额外限速
- **Stage 2**：SwissTargetPrediction 有反爬限制
  - 每个进程使用独立浏览器 + stealth 模式
  - 进程数控制在 2-4 个
  - 失败自动重试（`SwissTargetPredictor.run()` 已内置重试 3 次）

## 8. 错误处理

| 阶段 | 错误类型 | 处理方式 |
|------|----------|----------|
| Stage 1 | PubChem 查询失败 | 记录错误，继续处理其他分子 |
| Stage 1 | 分子名称无结果 | 记录错误，跳过 Stage 2 |
| Stage 2 | 浏览器启动失败 | worker 内部重试 3 次 |
| Stage 2 | 页面加载超时 | worker 内部重试 3 次 |
| Stage 2 | CSV 下载失败 | worker 内部重试 3 次 |
