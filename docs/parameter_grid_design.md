# 参数网格设计文档

## 敏感性分析参数网格

### 参数定义

| 参数 | 含义 | 取值范围 | 选择依据 |
|------|------|----------|----------|
| **Prob** | SwissTargetPrediction Probability 阈值 | [0, 0.09, 0.1] | 0 表示保留 Probability > 0 的预测靶点；0.09~0.1 为常用默认值附近细粒度扫描；0.2 已作为失效边界保留在探索记录中，不纳入主网格 |
| **STRING** | STRING 数据库 combined_score 阈值 | [0.30, 0.35, 0.40, 0.45, 0.50, 0.70] | 覆盖 STRING 中等~高置信度区间，0.30~0.50 间加密采样，0.70 为高置信度标准 |
| **TopK** | PPI 网络 Degree 排序取前 K 个基因 | [25, 30, 35, 40] | 网络药理学文献常用 hub 基因数量范围 |

### 网格规模

- **总组合数**: 3 (Prob) × 6 (STRING) × 4 (TopK) = **72**
- **Pvalue 固定**: 0.01（不影响靶点筛选），另单独对比 0.05

### 设计说明

1. **Prob=0 的定义**: 主分析中使用 `Probability > threshold`，因此 Prob=0 对应保留所有非零概率预测靶点。
2. **Prob=0.2 不纳入主网格**: 预实验显示该阈值会导致靶点过少并进入富集失效区间，适合作为边界/反例，不作为主结论统计分母。
3. **STRING 聚焦 0.30~0.70**: 排除了 0（无意义）和 0.9（过于严格），在常用区间内加密采样。
4. **Pvalue 独立处理**: 不参与网格组合，因为 Pvalue 只影响富集显著性判定，不影响靶点筛选，分层处理逻辑更清晰。
