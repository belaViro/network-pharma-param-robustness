# GNN 靶点筛选方案

## 研究目标

证明 **GNN 筛选 > Top-30 Degree 传统方法**

```
当前流程（传统）:
PPI网络 → Degree排序 → 取Top-30 → 富集分析

改进流程（GNN）:
PPI网络 → GNN评分 → 取Top-30 → 富集分析
```

---

## 核心对比设计

| 方法 | 步骤 |
|------|------|
| **Degree（基准）** | 按 STRING degree 排序，取 Top-30 |
| **GNN（改进）** | GAT 评分排序，取 Top-30 |

---

## 推荐架构：GAT (Graph Attention Network)

- 注意力机制天然适合"哪些节点更重要"的任务
- 可解释性强（注意力权重 = 重要性评分）
- PyTorch Geometric 支持良好

---

## 数据来源

```
Stage4: 疾病基因交集 → 作为正例标签
其余基因 → 作为负例/无标签
```

## 二区期刊评估指标体系

### 第一层：核心贡献指标（必须）

| 指标 | 意义 | 目标 | 计算方式 |
|------|------|------|---------|
| **氧化应激通路富集数** | 直接验证方法有效性 | GNN > Degree | Count(氧化应激通路) |
| **平均 Enrichment Factor** | 通路关联强度 | GNN > Degree | mean(EF) |
| **最小 P-value** | 最高置信度结果 | GNN < Degree | min(Adjusted P-value) |

### 第二层：方法差异指标（证明 GNN 学到了新东西）

| 指标 | 意义 | 目标 | 计算方式 |
|------|------|------|---------|
| **Overlap Rate** | 两种方法差异程度 | 0.3 ~ 0.6 | \|GNN ∩ Degree\| / 30 |
| **新靶点数** | GNN 独有的新发现 | > 5 个 | GNN - Degree |
| **疾病基因召回率** | 方法对已知疾病的覆盖 | GNN >= Degree | \|Top30 ∩ Disease\| / 30 |

### 第三层：网络拓扑指标（展示 GNN 捕捉到结构信息）

| 指标 | 意义 | 计算方式 |
|------|------|---------|
| **平均 Betweenness** | 节点在网络中的桥梁作用 | NetworkX betweenness_centrality |
| **平均 PageRank** | 节点在网络中的重要性 | NetworkX pagerank |
| **子图密度** | Top-30 构成的子网络紧密程度 | edges / 435 |

---

## 评估指标详解

### 1. 富集分析类

| 指标 | 说明 | 计算方式 |
|------|------|---------|
| **显著通路总数** | 所有 KEGG/GO 显著通路数 | Count(Adj P < 0.05) |
| **GO_BP 显著数** | 生物学过程条目数 | GO 富集结果 |
| **GO_MF 显著数** | 分子功能条目数 | GO 富集结果 |
| **平均 EF** | 所有显著通路的 EF 均值 | mean(EF) |
| **最大 EF** | 最显著通路的 EF | max(EF) |
| **最小 P-value** | 最强的统计显著性 | min(Adjusted P-value) |

### 2. 靶点质量类

| 指标 | 说明 | 计算方式 |
|------|------|---------|
| **疾病基因召回率** | Top-30 中有多少是已知疾病基因 | \|Top30 ∩ Disease\| / 30 |
| **Degree Top-30 重叠率** | GNN 与 Degree 重叠的靶点数 | \|GNN ∩ Degree\| / 30 |
| **新靶点数** | GNN 独有的、不在 Degree Top-30 的 | GNN - Degree |

### 3. 网络指标对比

| 指标 | 说明 | 计算方式 |
|------|------|---------|
| **平均 Degree** | Top-30 的平均连接数 | mean(degree) |
| **平均 Betweenness** | 介数中心性 | NetworkX 计算 |
| **平均 PageRank** | PageRank 值 | NetworkX 计算 |
| **网络密度** | Top-30 构成的子图密度 | edges / (n*(n-1)/2) |
